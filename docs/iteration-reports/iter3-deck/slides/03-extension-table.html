양식 #2 — Iter3 확장기능 6종 03 / 24
6 NEW · 4 OBSERVER + 2 DOMAIN EXTENSION

iter3가 더한 6개 확장기능

4개는 Observer 패턴 적용 — 부수효과를 호출자에서 떼어 listener로 분리. 특히 항공 e-Ticket 발급과 6개 대도시 우등고속 버스티켓 발매를 연계한다.

EXT-01 · OBSERVER
좌석 hold 만료 자동화

결제 미완료 좌석을 15분 후 자동 회수. SeatHoldMonitor.sweep()이 만료 좌석을 발견하면 SeatHoldExpiredEvent를 발행하고, ReservationHoldListener가 좌석을 해제하고 Reservation을 Cancelled로 전이.

SeatHoldMonitor → SeatHoldExpiredEvent → ReservationHoldListener
EXT-02 · OBSERVER
결제 실패 자동 취소

iter2까지는 호출부가 직접 handlePaymentFailure를 호출했다. iter3에서는 PaymentProcessor가 PaymentFailedEvent를 발행하고 listener가 자동으로 전이를 수행.

PaymentProcessor → PaymentFailedEvent → ReservationAutoCancelListener
EXT-03 · OBSERVER
FlightSchedule 변경 전파

관리자가 changeStatus(CANCELLED)를 호출하면 해당 schedule을 itinerary에 포함하는 모든 Reservation에 영향이 전파된다. AffectedReservationListener가 ReservationRegistry를 순회.

FlightSchedule → FlightStatusChangedEvent → AffectedReservationListener
EXT-04 · OBSERVER
항공권 + 우등고속 버스티켓 연계

항공 e-Ticket 발급 완료 시 TicketIssuedEvent를 발행한다. BusTicketPurchaseListener가 선택된 6개 대도시 중 하나의 우등고속 버스티켓을 자동 발매한다.

TicketPurchasePublisher → TicketIssuedEvent → BusTicketPurchaseListener
EXT-05 · ITINERARY
Connecting + Multi-city

Itinerary.connecting(first, second)로 2-leg 환승 일정을 만든다. isConnectionTimeValid(MCT)가 환승 시간이 최소 60분(국내) / 90분(국제) 이상인지 검증.

Itinerary.DIRECT | CONNECTING | MULTI_CITY · MCT 60 / 90
EXT-06 · PAYMENT
마일리지 적용 결제

PaymentMethod.MILEAGE 신규 enum. PaymentProcessor.processMileagePayment(account, cost, pnr)가 MileageAccount.withdraw로 차감하고 실패 시 PaymentFailedEvent 발행 — 일반 결제 실패 경로와 동일하게 자동 취소된다. MockSkypassInterface가 외부 Skypass 시스템의 in-memory mock을 제공.

PaymentMethod.MILEAGE · MileageAccount.withdraw · MockSkypassInterface
Iter 3 · Extensions 4 × Observer (accent) + 2 × Domain extension
